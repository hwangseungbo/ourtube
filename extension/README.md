# 위튜브 Chrome 확장 프로그램 0.8.1

홈페이지에서 URL을 입력한 뒤 새 다운로드 탭을 열지 않고 사용자 Chrome에서 영상·음성을 내려받아 MP4로
결합합니다.

## 테스트 순서

1. 프로젝트의 `위튜브 실행.bat`를 실행합니다.
2. Chrome의 `chrome://extensions`에서 이 `extension` 폴더를 압축해제 확장 프로그램으로 로드합니다.
3. 기존에 로드했다면 **새로고침**을 누르고 버전 `0.8.1`을 확인합니다.
4. 홈페이지 <http://127.0.0.1:4545>도 새로고침합니다.
5. 권한이 있는 YouTube URL과 권리 확인을 입력하고 **새 탭 없이 영상 분석**을 누릅니다.
6. 같은 홈페이지에 표시된 화질을 선택하고 **내 PC에서 다운로드 시작**을 누릅니다.
7. 진행률이 100%가 되면 Chrome의 기본 다운로드 폴더에서 MP4를 확인합니다.

## 동작 방식

- 1차: Offscreen 문서 안의 숨겨진 YouTube 임베드 플레이어에서 SABR 정보를 확인합니다.
- 2차 안전장치: 1차가 실패하면 비활성 임시 YouTube 탭을 사용하고 포착 직후 자동으로 닫습니다.
- 다운로드와 MP4 결합: Offscreen 문서에서 SABR와 Mediabunny를 사용합니다.
- 임시 저장: 확장 프로그램 OPFS에 기록하며 완료·실패·취소 뒤 삭제합니다.
- 최종 저장: Chrome Downloads API로 기본 다운로드 폴더에 저장합니다.

별도의 확장 프로그램 다운로드 탭은 열리지 않습니다. 1차 경로가 성공하면 브라우저 탭 자체를 새로 만들지
않으며, 2차 경로에서도 사용자가 보고 있는 홈페이지 탭은 전환되지 않습니다.

결합은 H.264/AAC 등 인코딩 패킷을 그대로 복사하는 remux 방식이므로 일반적으로 GPU나 재인코딩이
필요하지 않습니다. 대용량 네트워크 요청, MP4 결합, 임시 파일과 최종 파일 저장은 사용자 PC에서
처리됩니다.
