다운로드 전 확인

현재 설치 파일에는 유료 코드 서명이 적용되지 않아 Windows에 알 수 없는 게시자로 표시될 수 있습니다. 다운로드 주소가 github.com/hwangseungbo/ourtube-releases인지 확인하고, 아래 SHA-256 값이 다르면 실행하지 마세요.

SHA-256 771B371D7CD1F0134B8379589C2F1EBB6E186FFBB54996A11146A284B2EA54D0

PowerShell에서 Get-FileHash .\OurTube-Setup-0.2.6.exe -Algorithm SHA256으로 다운로드한 파일을 직접 확인할 수 있습니다.

업데이트 방식

  • 앱은 실행 후 이 공식 사이트에서 최신 버전 번호와 체크섬만 확인합니다.
  • 새 버전이 있으면 사용자가 앱 안에서 업데이트 다운로드 여부를 선택합니다.
  • 동의한 경우에만 공식 GitHub 배포 저장소에서 변경된 부분을 우선 내려받습니다.
  • 다운로드와 무결성 검증이 끝난 뒤 사용자가 다시 동의해야 앱을 재시작해 설치합니다.
  • 인앱 업데이트 과정에서는 홈페이지나 브라우저를 열지 않습니다.
  • 앱 화면의 버전 버튼으로 언제든 업데이트를 직접 확인할 수 있습니다.
