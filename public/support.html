자주 묻는 질문

아워튜브는 서버에서 영상을 다운로드하나요?

아닙니다. 영상·음성 요청과 MP4 결합은 Windows 앱을 통해 사용자 PC에서 진행됩니다. 홈페이지 서버는 YouTube 미디어 파일을 대신 다운로드하거나 저장하지 않습니다.

Chrome 확장 프로그램이 필요한가요?

필요하지 않습니다. 현재 권장 방식은 Windows 앱이며, 영상 주소 입력부터 화질 선택과 저장까지 앱 안에서 진행합니다.

완성된 파일은 어디에 저장되나요?

다운로드를 시작할 때 이용자가 선택한 폴더에 MP4 파일로 저장됩니다. 앱 하단의 저장 폴더 열기 버튼으로 기본 저장 폴더를 확인할 수도 있습니다.

화질 선택에 원하는 해상도가 없습니다.

원본 영상이 제공하는 형식, YouTube 응답 및 현재 브라우저 환경에 따라 선택 가능한 화질이 달라질 수 있습니다.

분석 시간이 초과되거나 미디어 요청을 찾지 못합니다.

앱 화면의 버전 버튼을 눌러 최신 버전인지 확인한 뒤 다시 시도해 주세요. 보안 프로그램, 방화벽 또는 네트워크 설정이 YouTube·Googlevideo 요청을 차단하는지도 확인해 주세요.

어떤 영상을 저장할 수 있나요?

본인이 제작했거나 저작권자 또는 서비스 제공자로부터 저장과 이용을 허락받은 영상만 처리해야 합니다. 권한이 불확실한 영상은 저장하지 마세요.

삭제하거나 초기화하려면 어떻게 하나요?

Windows 설정의 설치된 앱에서 아워튜브를 제거할 수 있습니다. 완성 파일은 이용자가 선택한 저장 폴더에서 직접 삭제할 수 있으며, 작업용 임시 파일은 작업 종료 후 자동 삭제됩니다.

권리 침해 및 보안 신고

저작권 또는 기타 권리 침해, 보안 취약점, 개인정보 문제를 발견했다면 제목에 신고 유형을 표시해 support@ourtube.kr로 보내주세요. 신고자의 권리와 개인정보를 존중하며 필요한 범위에서 확인하고 조치합니다.
