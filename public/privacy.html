개인정보 처리방침

아워튜브(OurTube) 운영자(이하 “운영자”)는 웹사이트, Chrome 확장 프로그램과 Windows 앱을 제공하면서 어떤 정보를 왜 처리하는지, 어디에 보관하는지 투명하게 안내합니다.

시행일: 2026년 7월 23일 · 버전 1.0

1. 핵심 요약

YouTube 주소, 영상 정보, 미디어 데이터와 완성 파일은 사용자의 기기에서 처리됩니다. 운영자는 이를 별도 애플리케이션 서버로 전송하거나 저장하지 않습니다.

  • 회원가입, 로그인 또는 결제 정보를 요구하지 않습니다.
  • 개인화 광고를 제공하거나 사용자 데이터를 판매하지 않습니다.
  • 다운로드 작업에 필요한 임시 정보는 브라우저 세션 또는 Windows 앱의 로컬 임시 저장소에서 처리됩니다.
  • 문의 이메일을 보낼 때에만 회신에 필요한 정보가 운영자에게 전달됩니다.

3. 웹 탐색 활동과 확장 권한

확장 프로그램은 사용자가 요청한 기능을 제공하기 위해 아워튜브 페이지, YouTube 페이지 및 Googlevideo 미디어 요청에 접근합니다. 이 과정에서 현재 영상의 URL, 플레이어 응답과 미디어 요청 정보가 사용자 기기에서 일시적으로 처리될 수 있습니다.

운영자는 사용자의 전체 방문 기록을 수집하지 않으며, 처리된 웹 탐색 활동을 광고, 신용 평가, 데이터 판매 또는 기능 제공과 무관한 분석에 사용하지 않습니다. 인증 쿠키나 비밀번호를 읽기 위한 권한을 요청하지 않습니다.

4. 외부 서비스 및 처리 위탁

Cloudflare

웹사이트 호스팅, 콘텐츠 전송, TLS 및 보안을 위해 Cloudflare, Inc.의 Pages 서비스를 사용합니다. 접속 과정의 기술 정보는 Cloudflare 개인정보 보호정책에 따라 처리될 수 있습니다.

Google 및 YouTube

영상 확인과 미디어 요청은 사용자의 브라우저 또는 Windows 앱에서 Google·YouTube 서비스로 직접 전송됩니다. 해당 서비스의 정보 처리는 Google 및 YouTube의 정책이 적용됩니다. 운영자는 이 통신을 통해 사용자의 Google 계정 비밀번호나 인증 정보를 수신하지 않습니다.

5. 제3자 제공과 판매

운영자는 사용자 정보를 제3자에게 판매하지 않으며, 개인화 광고 또는 데이터 중개 목적으로 제공하지 않습니다. 법령에 따른 요청, 사용자의 별도 동의 또는 서비스 보안상 필요한 경우를 제외하고 문의 정보를 외부에 제공하지 않습니다.

6. 파기와 사용자 선택권

  • 확장 프로그램의 세션 정보는 작업 종료 또는 브라우저 세션 종료 시 제거됩니다.
  • 임시 MP4 파일은 작업 완료·취소·실패 후 제거됩니다.
  • 완성된 다운로드 파일은 사용자가 직접 관리하고 삭제할 수 있습니다.
  • 확장 프로그램을 제거하거나 Chrome의 확장 프로그램 데이터를 삭제해 로컬 정보를 지울 수 있습니다.
  • Windows 앱을 제거해 앱 구성 요소를 삭제할 수 있으며, 사용자가 저장한 완성 파일은 별도로 관리합니다.
  • 문의 정보의 열람·정정·삭제를 원하면 아래 연락처로 요청할 수 있습니다.

7. 안전성 확보 조치

운영자는 필요한 권한만 사용하고, 신뢰된 출처만 허용하며, 웹사이트 통신에 HTTPS를 사용합니다. 미디어 결합과 임시 파일 처리는 가능한 범위에서 사용자 기기 안에서 수행하고, 작업 식별자와 임시 데이터는 목적 달성 후 제거합니다.

8. Chrome 웹 스토어 제한적 사용 준수

아워튜브가 Chrome 및 Google 서비스로부터 처리하는 정보의 사용은 Chrome 웹 스토어 사용자 데이터 정책과 Limited Use(제한적 사용) 요구사항을 준수합니다.

정보는 공개된 단일 목적 기능을 제공하는 데 필요한 범위로 제한하며, 맞춤 광고, 재판매, 신용 평가 또는 기능과 무관한 목적으로 사용하거나 이전하지 않습니다.

9. 아동의 개인정보

아워튜브는 아동을 대상으로 개인정보를 의도적으로 수집하지 않습니다. 법정대리인의 동의가 필요한 이용자가 문의를 보내는 경우 법정대리인의 도움을 받아 주시기 바랍니다.
