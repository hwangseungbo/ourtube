# 법률·플랫폼 정책 검토

검토 기준일: 2026-07-23 · 대상 지역: 대한민국 · 법률 자문이 아닌 제품 설계 참고자료

## 결론

개인용 로컬 도구를 만드는 행위와 특정 영상을 다운로드하는 행위의 적법성은 별개입니다. 본인 소유,
권리자의 명시적 허락, 서비스가 제공한 다운로드 기능처럼 권한이 분명한 콘텐츠만 대상으로 제한하는
것이 현재 제품의 안전한 경계입니다.

범용 YouTube 다운로드 기능을 Chrome 웹스토어에 공개 배포하는 것은 위험도가 높습니다. 스토어가 비디오
다운로더라는 유형 자체를 모두 금지하지는 않지만, 저작권 미디어의 무단 다운로드를 조장·지원하는
제품은 금지합니다. 스토어 심사를 통과하더라도 YouTube 이용약관 또는 저작권법 준수를 보증하지
않습니다.

현재 공개 배포의 제품 설명은 범용 “유튜브 다운로드”보다 본인이 제작했거나
저장 허가를 받은 영상의 백업 용도를 우선합니다. 이는 위험을 줄이는 제품 경계이지,
YouTube 이용약관과의 충돌 가능성이나 개별 다운로드의 적법성을 보증하지 않습니다.

## 현재 적용한 위험 완화

- 홈페이지 제목·설명·주요 문구를 “내 영상·허가받은 영상 백업” 중심으로 변경
- 공식 다운로드 페이지에 권한 있는 콘텐츠만 지원한다는 안내를 다운로드 버튼보다 먼저 표시
- 이용약관에서 공개 상태와 저장 권한을 구분하고 기술적 보호조치 우회를 금지
- 유료·비공개·로그인·연령·지역 제한 우회와 재생목록 대량 수집을 지원 범위에서 제외
- 권리침해 및 보안 신고 창구를 `support@ourtube.kr`로 공개
- 자체 코드를 GPL-3.0-or-later로 공개하고 제3자 라이선스·상표·코드 서명 정책을 분리

위 조치는 면책 수단이 아닙니다. 대외 홍보 확대, 광고·유료화 또는 SignPath 신청
전에는 Windows 앱의 실제 네트워크 흐름과 yt-dlp·FFmpeg 사용 방식까지 포함해
대한민국 저작권 전문 변호사의 검토를 받아야 합니다.

## 사용 시나리오별 위험도

| 시나리오                                    | 판단                                                                                                                           |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 내가 업로드하고 권리를 보유한 영상의 백업   | 저작권 위험은 낮지만 가능하면 YouTube Studio 또는 Google Takeout 같은 공식 기능을 우선 사용합니다.                             |
| 권리자가 파일 저장을 명시적으로 허락한 영상 | 허락 범위와 사용 목적을 보관하고 그 범위에서만 사용합니다. YouTube 약관 이슈는 별도로 남을 수 있습니다.                        |
| Creative Commons 표시 영상                  | 라이선스 조건과 실제 업로더의 권리 보유 여부를 확인합니다. YouTube 밖으로 파일을 추출하는 행위의 약관 문제는 별도입니다.       |
| 개인 감상용 일반 영상                       | 한국 저작권법상 사적 복제 논점이 있을 수 있으나 YouTube 약관상 허용된다고 단정할 수 없습니다. 제품의 권장 용도에서 제외합니다. |
| 유료·회원·연령·지역 제한 우회               | 구현하지 않습니다. 법률·약관·스토어 정책 위험이 큽니다.                                                                        |
| 다운로드 파일 재업로드·판매·공유            | 권리자 허락이나 명확한 법적 근거 없이는 금지 대상으로 봅니다.                                                                  |

## 공개 배포 전 체크리스트

- 대한민국 저작권 전문 변호사에게 실제 기능과 마케팅 문구를 함께 검토받기
- 지원 대상을 본인 소유·명시적 허락 콘텐츠로 기능적으로 제한할 방법 확정하기
- 권리 확인 로그를 수집한다면 보관 기간, 삭제 기능, 개인정보처리방침 정하기
- YouTube 계정 쿠키·세션·비밀번호를 수집하거나 전송하지 않기
- DRM 및 로그인·유료·연령·지역 제한 우회 기능을 제공하지 않기
- 확장 프로그램 설명에 지원 범위와 로컬 네이티브 앱 설치 사실을 정확히 밝히기
- `activeTab` 등 최소 권한만 요청하고 광범위한 방문 기록 권한을 피하기
- 스토어 심사 결과와 법적 적법성을 별개로 판단하기
