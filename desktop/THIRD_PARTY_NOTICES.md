# Third-party components

아워튜브 Windows 데스크톱 PoC는 다음 실행 파일을 별도 프로세스로 사용합니다.

## yt-dlp

- Project: https://github.com/yt-dlp/yt-dlp
- License: The Unlicense
- Included artifact: `yt-dlp.exe`
- Source and releases: https://github.com/yt-dlp/yt-dlp

## FFmpeg

- Project: https://ffmpeg.org/
- Binary provider: https://github.com/eugeneware/ffmpeg-static
- Included binary license: GPL-3.0-or-later
- Corresponding binary release source information:
  https://github.com/eugeneware/ffmpeg-static

공개 배포 전에는 포함된 정확한 FFmpeg 빌드의 소스 제공 의무와 전체 라이선스 고지를 다시 검토해야 합니다.
